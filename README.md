# 💻 MF0227_3 · Programación Orientada a Objetos

![Programación Orientada a Objetos](./images/portada-curso.png)

**Aprende a diseñar, desarrollar y organizar soluciones software con un enfoque orientado a objetos.**

Bienvenido/a al repositorio formativo del módulo **MF0227_3 – Programación orientada a objetos**, perteneciente al certificado profesional **IFCD0112 – Programación con lenguajes orientados a objetos y bases de datos relacionales**.

Este espacio está diseñado como apoyo al aprendizaje, la práctica y el desarrollo de competencias de programación, mediante explicaciones, ejemplos de código, ejercicios y actividades prácticas.

---

## 🎯 Objetivos del curso

Al finalizar el proceso formativo, el alumnado podrá:

- Comprender los fundamentos de la programación orientada a objetos.
- Identificar y utilizar clases y objetos.
- Aplicar atributos, métodos y constructores.
- Comprender los principios de encapsulación, herencia y polimorfismo.
- Organizar el código mediante estructuras reutilizables.
- Desarrollar aplicaciones utilizando un lenguaje orientado a objetos.
- Aplicar buenas prácticas de programación.
- Analizar, diseñar y resolver problemas mediante soluciones software.
